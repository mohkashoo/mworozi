=== AGRISCOPE AI — Project Brief ===
Frontiers GenAI Hackathon 2026 | Track 01: Agriculture & BioSystems
3 Crops: Cassava, Maize, Yam | Region: Rwanda, East Africa

=========================================
THE PROBLEM
=========================================
Rwandan smallholders lose 30-50% of harvests to preventable crop diseases.
Extension officers are outnumbered 1:10,000. Farmers lack scouting plans,
climate-driven growing advice, and direct market access. Information that
exists (FAO, IITA, CGIAR) never reaches the field. Farmers decide blind.

=========================================
CORE FEATURES
=========================================

Smart Scouting Engine
  Weekly scout plan: when, where, and what to check (5 spots * 4 plants =
  20 sample points, edges prioritized). Top 3 threats per growth stage.
  Every recommendation cites source: FAO, IITA, CGIAR, or Open-Meteo.

Photo Diagnosis + Human Approval Layer
  Farmer snaps a photo. Gemini Vision returns disease, severity, treatment.
  Low confidence (<85%) triggers "Human Verification Recommended" flag.
  Accept, override, or ask follow-up before acting on any diagnosis.

Climate-Driven Growing Calendar
  Personalized season-long calendar: land prep, planting, weeding, fertilizer
  timing, harvest window. Real-time adaptation: "delay planting 5 days —
  rains coming late this year." Budget-constrained (stays within RWF limit).

Market Connect
  Harvest estimate from plot size + crop. Farmgate vs market price (sell now
  vs hold). 5 seeded buyers per crop with WhatsApp-ready outreach messages
  generated in farmer's language (Kinyarwanda, Swahili, French).

Neighbor Early Warning
  If a confirmed disease is detected within 5km radius, all nearby plots
  receive an alert with the specific threat + prevention steps.

=========================================
HOW IT WORKS
=========================================
1. Farmer registers plot (crop, location, size, planting date, budget)
2. App generates weekly scout plan + personalized growing calendar
3. Farmer uploads scout photo -> Gemini diagnoses -> human reviews
4. Low-confidence results flag for extension officer verification
5. Market tab shows buyers, prices, and AI-generated WhatsApp messages
6. Assessment history + follow-up plans track every crop journey

Demo walkthrough: User registers a maize plot in Kigali. System generates
a scout plan flagging Fall Armyworm risk (cited: FAO). User snaps a leaf
photo -> Gemini confirms Armyworm, Moderate, with treatment steps. User
clicks "Send via WhatsApp" -> farmer in Rulindo receives the full report
in Kinyarwanda. User switches to Market tab -> sees 5 maize buyers, selects
MINAGRI Grain Reserve, taps WhatsApp -> AI-written outreach message opens.

=========================================
TECH STACK
=========================================
Frontend:   Streamlit + Bootstrap Icons + Inter font
AI:         Gemini 3.6-flash (vision + text generation)
Weather:    Open-Meteo API (free, no API key)
Database:   SQLite (plots, assessments, follow plans, alerts)
Languages:  English, Kinyarwanda, Swahili, French
Deploy:     Streamlit Cloud (auto-deploy from GitHub)
APIs:       WhatsApp Web (free sharing), SMS protocol

=========================================
BONUS FEATURES (Judging Criteria)
=========================================
Human Approval: Low-confidence diagnoses require verification before action
Evaluation: AI confidence score per diagnosis, severity level displayed
Personalization: Budget constraint, location weather, crop variety
Accessibility: 4 languages, Voice TTS, SMS for basic phones

=========================================
WHY THIS WINS
=========================================
  End-to-end farmer journey: Scout -> Diagnose -> Treat -> Grow -> Sell
  Every claim cited (FAO, IITA, CGIAR, weather API)
  Works on basic phones (SMS) to smartphones (WhatsApp, camera)
  Zero cost: free APIs, free deployment tier
